Taruh file slide di folder ini.

Penamaan : slide-{angka}.{ext}   contoh: slide-1.png, slide-2.mp4, slide-10.jpg
Ekstensi : png, jpg, jpeg, webp, gif, mp4, webm  (huruf kecil)
Urutan   : berdasarkan angka (slide-2 tampil sebelum slide-10)
Ganti    : timpa file dengan nama yang sama
Tambah   : tambahkan file dengan angka berikutnya
